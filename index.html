About the short version

Programmer, and one day a full time game developer

I started programming because I wanted to know how games actually put an image on screen, and that question never really closed. It pulled me into graphics APIs, then into engines, then into building small games on my own.

Right now I work solo: design, code, art direction, testing, all of it. That means I am comfortable owning a feature end to end and shipping it without someone breaking it down for me first. I like problems where the constraint is real, a frame budget, a memory limit, a device that should not be able to run this.

The goal is to do this full time. Until then I keep building in public on GitHub, and I am open to graphics, gameplay, tools or QA focused roles where I can learn from people who have shipped more than I have.

Currently

  • Building A solo game project in Godot, with C# on the gameplay side
  • Learning Vulkan compute and modern render graph design
  • Planning A home lab rack: custom NAS, backups, home automation
  • Open to Junior and mid graphics, gameplay, tools or QA roles
  • Based in Greece, EU, comfortable remote
